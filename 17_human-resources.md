Human Resources

Use the Human Resources module to enter and maintain information about company employees, and to perform the following

related tasks:

Enter and maintain general and personal employee information, such as age, marital status, passport and ID number,

phone numbers, and home and work addresses.

Manage information regarding employee education, previous job records, results of professional reviews, and absences.

Analyze employee costs and salaries.

Create various reports and employee lists to run your business more eﬃciently.

Creating Employee Master Data

Context

Use this procedure to enter work-related and personal data about each employee.

Procedure

1. From the SAP Business One Main Menu, choose  Human Resources

 Employee Master Data .

The Employee Master Data window appears.

2. Choose

, and in the General Area fields, specify the required general information. You can also insert a picture.

  Note

In the User Code field, when choosing the Define New option to define a new user to link to, you can choose whether to

have fields User Code, User Name, Employee, E-Mail, Mobile Phone, Fax, Branch, and Department filled with values

from the employee master data.

3. On the Address tab, specify the employee's work and home addresses.

4. On the Membership tab, specify how the employee fits into the company and to which team he/she belongs.

5. On the Administration tab, specify the employee’s employment period and status, as well as information about absences,

education, reviews, and previous employment.

6. On the Personal tab, specify information such as date of birth, marital status, and ID number.

7. On the Finance tab, specify the employee’s salary, cost, and necessary bank details.

8. On the Remarks tab, add comments, if required.

9. On the Attachments tab, link documents and files related to the employee.

10. Choose Add.

  Note

If you have not specified a user to link to, you are asked now whether to add a new user with the fields mentioned in the

note of Step 2 filled accordingly.

Target Path

The destination folder in which the attachment is stored.

When you upload an attachment, it is saved to the default target path folder which is set by your system administrators. However,

if it is needed, you can still change the target path manually. To do this, proceed as follows:

1. Right click the Target Path column to open the context menu. Choose Change Path.

subfolders in this window, if needed (subject to respective authorizations).

Time Sheet: Contents Tab

You can find the Time Recording table on the Contents tab. The system will retrieve an employee’s absence information from the

date range you defined in the general area, and fill it automatically in the Time Recording table. You cannot modify the absence

information in the Time Sheet window. You maintain the absence information of an employee using the Absence button on the

Administration tab of the Employee Master Data window.

Time Recording Table Fields

Date

Specify the work date.

Start Time, End Time

Enter the time your start and stop working.

Time Sheet Activity Type

From the dropdown menu, select the activity type.

Work Order No.

Select the work order number from the list of production orders. You can edit this field only if the person recording timesheet
hours has the type "user."

Financial Project

Select the financial project from the list of projects.

Cost Center

Select your cost center from the list of cost centers.

Labour Item

Select the labour item from the list of labour items.

Service Call

Select the service call you completed from the list of service calls.

Break

Input your break hours.

Nonbillable Time

Input the hours for which you will not be paid.

Eﬀective Time

Eﬀective time will be calculated automatically based on the inputted start time, end time and break.

Billable Time

Billable Time will be calculated automatically based on the inputted start time, end time, break and nonbillable time, for which you
